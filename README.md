# NovaFlow (⚠️Work in Progress!!)

> Plan intelligently. Collaborate instantly. Deliver confidently.

NovaFlow is an AI-powered, real-time collaborative project management platform. 
This repository contains the full-stack source code, built as a modular monolith within a `pnpm` workspace.

## Architecture
- **Frontend:** Next.js, React, Tailwind CSS
- **Backend:** NestJS, REST + WebSockets
- **Database:** PostgreSQL, Prisma ORM
- **Tooling:** pnpm monorepo
